# Efir 1.4.2

## What's changed

- Reduce redundant rendering, repeated layout work and state traffic. Paused
  screens no longer redraw unchanged snapshots, and a single reader no longer
  receives follower updates. Renaming a script no longer resends its text.
- Keep mirror and orientation controls in sync with keyboard shortcuts and
  connected readers. Preserve recent text, title and settings edits when closing
  native windows; bound macOS shutdown if a WebView stops responding.
- Preserve Android reader identity, calibration and saved position across
  reopening. Update connection QR codes without recreating the dialog, and
  correctly handle the first microphone permission request and cancelled speech
  sessions.
- Serialize desktop speech restarts, reuse audio buffers and stop recognition
  when the controller is hidden. Restore the active voice mode on return.
- Align local HTTP byte-range behavior and bound WebSocket messages, clients,
  queues and stalled writes. Keep macOS network selection across restarts.
- Avoid duplicate initial script transfers on the hosted website and share its
  static assets across language pages.

## Verification

The changes were checked with Chromium and WebKit synchronization and browser
regressions, 2,100 layout cases, local relay checks for Swift, Rust and Android,
slow-client stress tests, macOS window and shutdown tests, Android API 35
instrumentation including real permission dialogs, and offline Vosk PCM decoding.
Physical microphone recognition, iPhone screen locking and native Windows/Linux
GUI behavior were not verified on physical devices. Two existing FlyingFox path
normalization tests still differ on the local macOS Foundation version; relay
path-traversal checks pass.

## Downloads and installation

- macOS: `Efir-macOS.zip` — Apple Silicon and Intel, macOS 14+.
- Windows: `Efir-Windows-x64.zip` or `Efir-Windows-x64-setup.exe` — Windows
  10/11 x64 with Microsoft WebView2 Runtime.
- Linux: `Efir-Linux-x64.deb` or `Efir-Linux-arm64.deb` — Ubuntu 24.04+ or
  compatible dependencies.
- Android: `Efir-Android.apk` — Android 8+.

Extract the entire Windows portable folder and keep its resources and DLLs
beside `efir.exe`. Speech language models remain separate downloads.

The macOS app is ad hoc signed and not notarized. See the
[macOS opening instructions](../macos-distribution.md). Windows packages do not
have an Authenticode signature.

Android uses the same signing certificate as 1.4.1 and can update that version
without uninstalling. Certificate SHA-256:
`e85654fe8944ac49c6cc1d6e919106b76a1ae1e65044fe9a43225610050cd3bd`.

`Efir-1.4.2-SHA256.txt` contains the package checksums. Reload connected reader
pages after updating the host so the session uses the current version.
