# Efir 1.4.1

## What's changed

- Fix accumulated reading-position drift between phones and controller previews
  when browsers wrap a long script differently. Exact pixel positions are reused
  only when measured text geometry matches; other layouts follow word anchors.
- Add **Synchronize screens**, a two-arrow button below the preview. It aligns
  the controller and connected screens to the leading reader's current passage
  without restarting playback. Failed synchronization can be retried.
- Add independent **Left margin** and **Right margin** controls under
  **Advanced → Margins**. Settings profiles and backups retain them. Initially
  each side inherits **Side margins**; double-click its value to restore that
  behavior. Individual screen overrides continue to take precedence.

## Verification

The reported long-script drift was reproduced between Chromium and WebKit.
Regression checks cover late-script seeking, three-screen playback, manual
synchronization while reading, lost replies and retry, and margin persistence.
Existing browser, display, remote, performance and relay checks passed; all
2,100 responsive layout checks passed across six languages. These checks use
isolated browser profiles and the production Swift relay; they do not replace
testing on physical phones.

## Downloads and installation

| Platform | File | Requirements |
| --- | --- | --- |
| macOS | `Efir-macOS.zip` | Apple Silicon or Intel, macOS 14+ |
| Windows | `Efir-Windows-x64.zip` | Windows 10/11 x64, Microsoft WebView2 Runtime |
| Linux x64 | `Efir-Linux-x64.deb` | Ubuntu 24.04+ or compatible dependencies |
| Linux ARM64 | `Efir-Linux-arm64.deb` | Ubuntu 24.04+ or compatible dependencies |
| Android | `Efir-Android.apk` | Android 8+ |

Extract the entire Windows folder before launching `efir.exe`; keep `web/`,
`speech/` and the accompanying DLLs together. An NSIS installer is also provided.
Offline speech language models remain separate downloads.

The macOS app is ad hoc signed and not notarized. Follow the documented
[macOS opening steps](../macos-distribution.md). Windows packages do not have
an Authenticode signature.

Android 1.4.1 uses a new release signing certificate. Before upgrading an older
installation, export your scripts and settings, uninstall the old app, install
1.4.1 and restore the export. Future releases will reuse the new key, stored
outside the source checkout.

Android certificate SHA-256:
`e85654fe8944ac49c6cc1d6e919106b76a1ae1e65044fe9a43225610050cd3bd`.

`Efir-1.4.1-SHA256.txt` lists package checksums. Update the host application and
reload the connected reader pages so that the session uses the same version.
